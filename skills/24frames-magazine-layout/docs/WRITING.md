# 写作规范（影评 / 游戏评论）

## 编辑标准（优先级最高）
1. **观点优先**：先理解素材、形成一个明确判断再写。资料整理不是分析；没依据就承认不知道；不拔高。
2. **具体**：写具体的人物、场景、机制、细节；评价要说清好在哪。不用无支撑的抽象词（情感共鸣、沉浸感、精神内核、独特体验）和空洞网络词（神作、封神、破防、泪目）。剧情简介不是影评。
3. **语言**：少形容词、少比喻；不写对仗排比；严控「不是…而是…」「不仅…更…」「真正的…在于…」；段尾不加总结句；不造金句；少用引号、破折号、冒号和刻意短句；不装年轻，不加语气词。
4. **结构**：开头不宏大、不反问、不造悬念；结尾不升华；不凑三点，不写宣传腔。分段按完整意思，一般 3–6 句一段，不要一句一段。章节标题、独立引语、剧透提示各自成段。
5. **真实**：不虚构作者经历、情绪或群体共识。年份、剧情、因果必须核实；区分事实、观察、解读、评价；不编引语和数据；没核查不得声称核查过。
6. **不填充**：没东西可写就写短；多对象（片单等）先定选择标准，勉强符合的删。
7. **自检**：独立观点是什么？哪些是填充？有没有漂亮但空的句子？有没有替作者编的感受？观点不成立就推翻观点，不润色句子。

## 24帧 口吻
- 自称「24帧」或「24FRAMES PROJECT」，不用「观影团」。
- 影评可以尖锐，追问作品为什么这样运作（镜头、声音、结构、机制、工业与社群语境）；批评作品，对人保持尊重。少剧透，必须剧透时先提示。
- 标题写后果或洞见，不用「《片名》影评」「深度解析」。公众号标题栏写「标题｜24帧」。
- dek 一句话：从一个具体起点，说清作品把什么变成了什么。
- 章节名用完整中文句子（陈述或真问题），配一个英文词标签（如 CITY、VOICES、SOUND、WHY 24FRAMES）。最后一章说明为什么 24帧 想聊这部作品，并留一个出口（进群、映后、沙龙）。
- 第一段直接进入作品的开场处境，不铺背景。
- 专名用官方简体中文译名，首次出现括注原文。
